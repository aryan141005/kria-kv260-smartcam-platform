## Development Workflow

The documented workflow covers:

1. Hardware platform configuration using Vivado.
2. Hardware handoff through XSA.
3. Platform and acceleration development using Vitis.
4. Device-tree generation and embedded Linux configuration.
5. PetaLinux build and integration.

## Project Status

The documentation distinguishes completed reference-workflow stages from the PetaLinux build failures and deployment stages that remain unverified.
